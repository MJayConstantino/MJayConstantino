## A little about me

I'm a **Software Engineering student at Central Philippine University**, based in the Philippines. My focus is backend engineering, but I enjoy building the whole experience: the interface, API, database, and the pieces that connect them.

I've worked on government systems, organization platforms, startup products, freelance projects, and game jams. I'm also the **Lead Fullstack Developer at Centralian Developer Group – CPU**, and I've taken on team leadership and Scrum Master roles along the way.

I like projects that make me learn something new. Sometimes that's a better authentication flow. Sometimes it's a rewind mechanic, a webcam model, or getting a phone to talk to an irrigation controller over local Wi-Fi.

## Things I've built

### 🏛️ DALI Portal — Iloilo City Council

Contributed to the public portal and internal management system for the **Sangguniang Panlungsod ng Iloilo**: legislative records, council sessions, citizen inquiries, document publishing, and administrative workflows.

**Next.js · NestJS · TypeScript · Supabase · oRPC**

[Public portal](https://iloilocitycouncil.josearron.dev/en) · [Repository](https://github.com/peak-solutions-hub/dali-portal)

### 🧑‍💻 PSSE Website

Built an organization platform for the **Philippine Society of Software Engineers**, bringing public content, event registration, and authenticated officer administration together. Working across this stack has taken me deeper into TanStack, authentication, and Cloudflare's runtime and storage.

**TanStack Start · React · Prisma · Neon PostgreSQL · Better Auth · Cloudflare Workers & R2**

[Website](https://cpu-se.org) · [Repository](https://github.com/psse-dojo/psse-website)

### 🎟️ Game On — Event Platform & Interactive Launch Experience

Built the **AI Game On 2026 leaderboard platform** with participant profiles, live rankings, QR-assisted scoring, and staff workflows. Also created a **Godot launch experience** with an explorable Philippine map, regional puzzles, cinematic storytelling, voiceover, and launch media.

**Next.js · Supabase · TypeScript · Godot · GDScript · Shaders · Audio**

[Leaderboards](https://leaderboard.gameonportal.ph/leaderboards) · [Game On Portal](https://gameonportal.ph/)

### 🗺️ Lakbay Iloilo / Lagaw Iloilo

Worked on a travel companion with destination discovery, map quests, digital passport stamps, and AI-assisted itinerary planning. The project spans a web app, Expo mobile app, and NestJS API in a shared monorepo.

**React Native · Expo · Next.js · NestJS · Prisma · PostgreSQL · OpenRouter · Turborepo**

[Repository](https://github.com/iLovation/lakbay-iloilo)

### 🌱 Verdant — Local Smart Irrigation Demo

Connected an **Arduino UNO R4 WiFi** to a responsive dashboard for soil moisture, reservoir readings, irrigation, and ventilation. Includes automatic and timed manual controls, device acknowledgements, connection-state handling, and a separate simulator for development without hardware. The demo runs over local Wi-Fi.

**Arduino / C++ · TypeScript · Vite · Local HTTP · Sensors & Actuators**

[Repository](https://github.com/MJayConstantino/embedded-systems-final-proj)

### 👁️ PostureGuard — Computer Vision & Deep Learning

Built a course project that combines webcam capture, MediaPipe pose landmarks, a TensorFlow/Keras posture classifier, calibrated gaze tracking, and separate posture and distraction alerts. Includes data collection, training, evaluation, and a live Streamlit interface.

**Python · TensorFlow / Keras · MediaPipe · OpenCV · Streamlit**

[Repository](https://github.com/MJayConstantino/ML-final-proj)

### 🎮 Mix & Mash

Worked as a gameplay programmer on a **2D platform brawler** where players assemble a fighter from interchangeable heads, bodies, arms, and feet. Built around modular characters, physics, and LAN multiplayer during the Odyssey Festival 2024 game jam.

**Godot · GDScript · 2D Physics · LAN Multiplayer**

[Game page](https://gameonportal.ph/game/mix-mash) · [Gameplay demo](https://www.youtube.com/watch?v=W5ZHr-8YUac)
